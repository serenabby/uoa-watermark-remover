Background

On 14 August 2026 Anthropic published How Claude's text watermark works. To comply with the EU AI Act, Claude now includes a watermark in all the text it generates that cannot be removed easily (copy paste doesn't work, rewriting it does).

What it does

This software essientially removes the watermarks by deleting the hidden HTML headers that Anthropic uses, then replacing them with randomly generated meta tags (found in all text online anyway). Then, to be safe, the software rewrites the entire text within its new identity by copy pasting each letter in order in one by one. (The content is not altered, it looks the same to the human eye).

You do NOT need to be worried about the process rewording any of your text, it will only remove the watermark and rewrite the text in its original form.
